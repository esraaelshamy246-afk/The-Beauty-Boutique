# The Beauty Boutique

A responsive beauty products store website developed using HTML5, CSS3, and Bootstrap 5.

## Features
- Responsive website design.
- Beauty products showcase.
- Product pages.
- Pagination for browsing products.
- Order form.
- User-friendly interface.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## Project Purpose
This project was developed to practice front-end web development and create a responsive online shopping experience for beauty products.
